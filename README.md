# Проект - Nginx Log Analyzer 

Инструмент Nginx Log Analyzer служит для парсинга и анализа логов веб-сервеа Nginx.

### Стратегия ветвления
`main` - Основная ветка. Все новые функции и исправления попадают сюда через `merge request`
`release/X` - Ветки для подготовки релизов. Здесь проводятся финальные тесты, исправляются последние баги перед выпуском новой версии. Все исправления вносятся в отдельных bugfix- и hotfix-ветках, а не напрямую в release.
`feature/название_фичи` - Ветки для новой функциональности. Создаются от `main` и сливаются туда же через `merge request`
`bugfix/название_бага` - Ветки для оперативного исправления обнаруженных ошибок. Могут создаваться как от `main`-, так и от `release/*` -веток для срочных хотфиксов.
